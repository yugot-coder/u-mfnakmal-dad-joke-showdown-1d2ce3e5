# Dad Joke Showdown

One original dad joke, written to be told out loud at the dinner table —
a dad who starts a band called 999 Megabytes, and never gets a gig.

> I started a band called 999 Megabytes. We never got a gig.

## Run

```sh
python3 main.py
```

Writes the joke to `<MAKEFUN_OUTPUT_DIR>/entry.txt` (default
`/output/entry.txt`), then reads it back and validates it (1–200
characters, not only whitespace). Standard library only, deterministic,
no network.
